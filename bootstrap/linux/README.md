# 🐧 Linux — Família de Distribuições & Ambientes

> Diretório raiz de provisionamento para distribuições Linux de desktop, servidores e containers.

---

## 🎯 Finalidade

Reúne o ferramental de provisionamento para a família Linux, organizado por contexto operacional:
- **`desktop/`**: Distribuições de estação de trabalho gráfica (Fedora, Arch Linux, Debian).
- **`server/`**: Instâncias de servidores remotos na nuvem Oracle Cloud (`oracle-frigo`, `oracle-orbs`).
- **`container/`**: Subsistema de containers de sistema via Incus e LXC.

---

## 📂 Contextos Operacionais

| Contexto | Tipo | Descrição |
| :--- | :--- | :--- |
| [`desktop/`](desktop/README.md) | Estações de Trabalho | Catálogo por distribuição (Fedora, Arch Linux, Debian) |
| [`server/`](server/README.md) | Servidores em Nuvem | Setups atômicos para servidores Oracle Cloud e scripts SSH/SCP |
| [`container/`](container/README.md) | Containers de Sistema | Daemon Incus e LXC para containers leves |

---

## 🚀 Como Navegar

Para acessar as receitas prontas da sua estação de trabalho principal, navegue até [`desktop/`](desktop/README.md).
